Respaldo de insertos PDF por laboratorio
=========================================

Estos archivos son copias locales de los insertos (instrucciones de uso) 
disponibles en los portales de cada fabricante. Se guardan como respaldo 
para consulta sin conexion.

Para volver a descargar, ejecutar desde database/:
  powershell -ExecutionPolicy Bypass -File descargar_insertos.ps1

Carpetas:
- wiener_lab/   Wiener Lab (Argentina)
- spinreact/    SpinReact (Espana)
- linear/       Linear Chemicals (Espana)
- diasys/       DiaSys (Alemania)

Ver FUENTES_INSERTOS.md para lista completa de enlaces y mas fuentes.
